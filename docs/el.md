# Βοηθήστε μας να βελτιώσουμε την ελληνική έκδοση του Egosaru

Το [Egosaru](https://gstudio1.com/suggest/el/posts/google) είναι ένα δωρεάν εργαλείο που συγκεντρώνει με μία κίνηση τις προτάσεις αναζήτησης (αυτόματη συμπλήρωση) από το Google, το Bing, το YouTube και άλλες υπηρεσίες. Είναι διαθέσιμο σε 50 γλώσσες.

**Το ελληνικό κείμενο γράφτηκε με τη βοήθεια τεχνητής νοημοσύνης και δεν έχει ελεγχθεί ακόμη από φυσικό ομιλητή.** Ορισμένες φράσεις μπορεί να ακούγονται αφύσικες ή να περιέχουν λάθη. Αν μιλάτε ελληνικά, μπορείτε να βοηθήσετε σε ένα λεπτό.

## Πώς μπορείτε να βοηθήσετε

1. Ανοίξτε μια σελίδα του Egosaru στα ελληνικά: <https://gstudio1.com/suggest/el/posts/google>
2. Αν κάποια φράση δεν ακούγεται σωστά, ανοίξτε τη [φόρμα διορθώσεων μετάφρασης](https://github.com/YukiNakazawaAnzu/egosaru-i18n/issues/new/choose), επιλέξτε «Ελληνικά», επικολλήστε τη φράση και γράψτε πώς θα έπρεπε να είναι. Μπορείτε να γράψετε στα ελληνικά.
3. Δεν έχετε λογαριασμό στο GitHub; Χρησιμοποιήστε τη [φόρμα επικοινωνίας](https://gstudio1.com/suggest/el/contact).

Ακόμη και μία φράση είναι μεγάλη βοήθεια. Αν είστε εξοικειωμένοι με το GitHub, μπορείτε επίσης να επεξεργαστείτε απευθείας το [`lang/el.json`](../lang/el.json) και να ανοίξετε ένα pull request.

Όσοι στέλνουν χρήσιμες διορθώσεις μπορούν να λάβουν, ως ευχαριστώ, ένα δωρεάν κλειδί API με υψηλότερα όρια. Απλώς αναφέρετέ το στο μήνυμά σας. Με τη συγκατάθεσή σας, θα προσθέσουμε το όνομά σας στο [CONTRIBUTORS.md](../CONTRIBUTORS.md).
