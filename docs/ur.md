# اردو میں Egosaru کو بہتر بنانے میں مدد کریں

[Egosaru](https://gstudio1.com/suggest/ur/posts/google) ایک مفت ٹول ہے جو Google، Bing، YouTube اور دوسری سروسز کی سرچ تجاویز (آٹو کمپلیٹ) ایک ہی بار میں جمع کرتا ہے۔ یہ 50 زبانوں میں دستیاب ہے۔

**اردو متن AI سے لکھا گیا ہے اور ابھی تک کسی اہلِ زبان نے اس کی جانچ نہیں کی۔** کچھ جملے غیر فطری لگ سکتے ہیں یا غلط ہو سکتے ہیں۔ اگر آپ اردو پڑھ سکتے ہیں تو صرف ایک منٹ میں مدد کر سکتے ہیں۔

## مدد کیسے کریں

1. Egosaru کا اردو صفحہ کھولیں: <https://gstudio1.com/suggest/ur/posts/google>
2. اگر کوئی جملہ ٹھیک نہ لگے تو [ترجمے کی اصلاح کا فارم](https://github.com/YukiNakazawaAnzu/egosaru-i18n/issues/new/choose) کھولیں، "اردو" منتخب کریں، وہ جملہ پیسٹ کریں اور لکھیں کہ اسے کیسا ہونا چاہیے۔ آپ اردو میں لکھ سکتے ہیں۔
3. GitHub اکاؤنٹ نہیں ہے؟ تو اس کے بجائے [رابطہ فارم](https://gstudio1.com/suggest/ur/contact) استعمال کریں۔

ایک جملہ بھی بڑی مدد ہے۔ اگر آپ GitHub سے واقف ہیں تو [`lang/ur.json`](../lang/ur.json) میں براہِ راست ترمیم کر کے pull request بھی بھیج سکتے ہیں۔

## شکریہ

مفید اصلاحات بھیجنے والوں کو شکریے کے طور پر زیادہ حد والی مفت API کلید مل سکتی ہے۔ بس اپنی رپورٹ میں اس کا ذکر کر دیں۔ آپ کی اجازت سے ہم آپ کا نام [CONTRIBUTORS.md](../CONTRIBUTORS.md) میں شامل کریں گے۔
