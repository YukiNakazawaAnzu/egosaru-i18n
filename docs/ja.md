# 日本語のエゴサるを、よりよくするお手伝い

[エゴサる](https://gstudio1.com/suggest/posts/google) は、Google・Bing・YouTube などのサジェスト（検索候補）をまとめて取得できる無料ツールです。50 言語で使えます。

**日本語版はこのサービスの原文です。** ほかの 49 言語は、この日本語をもとに AI で翻訳したもので、母語話者の確認はまだ済んでいません。

## お手伝いの方法

1. エゴサるのページを開きます: <https://gstudio1.com/suggest/posts/google>
2. わかりにくい文や誤りを見つけたら、[翻訳の修正フォーム](https://github.com/YukiNakazawaAnzu/egosaru-i18n/issues/new/choose)で「日本語」を選び、その文と直し方を書いてください。日本語で書いてかまいません。
3. GitHub のアカウントが無い場合は、[お問い合わせ](https://gstudio1.com/suggest/contact)からどうぞ。

1 文だけでも助かります。GitHub に慣れている方は、[`lang/ja.json`](../lang/ja.json) を直接直して pull request を送ることもできます。

## お礼

役に立つ修正を送ってくださった方には、お礼として上限を広げた無料の API キーをお渡しします。報告のときにひとこと書き添えてください。ご了承いただければ、[CONTRIBUTORS.md](../CONTRIBUTORS.md) にお名前を載せます。
