# 한국어판 Egosaru를 더 좋게 만드는 데 힘을 보태 주세요

[Egosaru](https://gstudio1.com/suggest/ko/posts/google)는 Google, Bing, YouTube 등 여러 서비스의 서제스트(자동완성 검색어)를 한 번에 모아 주는 무료 도구입니다. 50개 언어로 제공됩니다.

**한국어 문장은 AI로 작성되었으며, 아직 원어민의 검토를 거치지 않았습니다.** 어색하거나 틀린 문장이 있을 수 있습니다. 한국어를 읽으실 수 있다면, 단 1분만 내어 도와주세요.

## 참여 방법

1. 한국어판 Egosaru 페이지를 열어 주세요: <https://gstudio1.com/suggest/ko/posts/google>
2. 어색한 문장이 보이면 [번역 수정 양식](https://github.com/YukiNakazawaAnzu/egosaru-i18n/issues/new/choose)을 열고 '한국어'를 선택한 뒤, 해당 문장을 붙여 넣고 어떻게 고치면 좋을지 적어 주세요. 한국어로 작성하셔도 됩니다.
3. GitHub 계정이 없으신가요? 대신 [문의 양식](https://gstudio1.com/suggest/ko/contact)을 이용해 주세요.

한 문장만 알려 주셔도 큰 도움이 됩니다. GitHub에 익숙하시다면 [`lang/ko.json`](../lang/ko.json)을 직접 수정해 pull request를 보내 주셔도 됩니다.

## 감사의 말씀

유용한 수정을 보내 주신 분께는 감사의 뜻으로 이용 한도를 늘린 무료 API 키를 드립니다. 제보하실 때 한마디 남겨 주세요. 동의해 주시면 [CONTRIBUTORS.md](../CONTRIBUTORS.md)에 성함을 올려 드립니다.
