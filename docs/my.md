# မြန်မာဘာသာ Egosaru ကို ပိုမိုကောင်းမွန်အောင် ကူညီပေးပါ

[Egosaru](https://gstudio1.com/suggest/my/posts/google) သည် Google၊ Bing၊ YouTube နှင့် အခြားဝန်ဆောင်မှုများမှ ရှာဖွေမှု အကြံပြုချက်များ (အလိုအလျောက် ဖြည့်စွက်ခြင်း) ကို တစ်ကြိမ်တည်းဖြင့် စုဆောင်းပေးသည့် အခမဲ့ ကိရိယာတစ်ခု ဖြစ်ပါသည်။ ဘာသာစကား 50 မျိုးဖြင့် အသုံးပြုနိုင်ပါသည်။

**မြန်မာဘာသာ စာသားများကို AI ဖြင့် ရေးသားထားပြီး မိခင်ဘာသာစကားပြောသူ တစ်ဦးဦးက မစစ်ဆေးရသေးပါ။** အချို့ဝါကျများသည် သဘာဝမကျခြင်း သို့မဟုတ် မှားယွင်းခြင်း ရှိနိုင်ပါသည်။ မြန်မာစာ ဖတ်တတ်ပါက တစ်မိနစ်အတွင်း ကူညီပေးနိုင်ပါသည်။

## ကူညီနိုင်ပုံ

1. Egosaru ၏ မြန်မာဘာသာ စာမျက်နှာကို ဖွင့်ပါ: <https://gstudio1.com/suggest/my/posts/google>
2. ဝါကျတစ်ခုခု မှားနေသည်ဟု ထင်ပါက [ဘာသာပြန် ပြင်ဆင်ရန် ဖောင်](https://github.com/YukiNakazawaAnzu/egosaru-i18n/issues/new/choose) ကို ဖွင့်ပြီး "မြန်မာ" ကို ရွေးပါ။ ထို့နောက် ထိုဝါကျကို ကူးထည့်ပြီး မည်သို့ ဖြစ်သင့်သည်ကို ရေးပါ။ မြန်မာလို ရေးနိုင်ပါသည်။
3. GitHub အကောင့် မရှိပါက [ဆက်သွယ်ရန် ဖောင်](https://gstudio1.com/suggest/my/contact) ကို အသုံးပြုနိုင်ပါသည်။

ဝါကျတစ်ကြောင်းတည်းဖြစ်စေ ကြီးမားသော အကူအညီ ဖြစ်ပါသည်။ GitHub ကို ကျွမ်းကျင်ပါက [`lang/my.json`](../lang/my.json) ကို တိုက်ရိုက်ပြင်ဆင်ပြီး pull request လည်း ပေးပို့နိုင်ပါသည်။

## ကျေးဇူးတင်ပါသည်

အသုံးဝင်သော ပြင်ဆင်ချက်များ ပေးပို့သူများသည် ကျေးဇူးတင်သည့်အနေဖြင့် ကန့်သတ်ချက် ပိုမြင့်သော အခမဲ့ API key ကို ရရှိနိုင်ပါသည်။ သင့်အစီရင်ခံစာတွင် ထိုအကြောင်း ဖော်ပြရုံသာ လိုပါသည်။ သင်၏ ခွင့်ပြုချက်ဖြင့် [CONTRIBUTORS.md](../CONTRIBUTORS.md) တွင် သင့်အမည်ကို ထည့်သွင်းဖော်ပြပါမည်။
