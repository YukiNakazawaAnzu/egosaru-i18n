# नेपालीमा Egosaru लाई अझ राम्रो बनाउन सहयोग गर्नुहोस्

[Egosaru](https://gstudio1.com/suggest/ne/posts/google) Google, Bing, YouTube लगायतका सेवाहरूबाट खोज सुझावहरू (अटोकम्प्लिट) एकैपटक सङ्कलन गर्ने निःशुल्क टुल हो। यो 50 भाषामा उपलब्ध छ।

**नेपाली पाठ AI को सहायताले लेखिएको हो र अहिलेसम्म कुनै नेपाली मातृभाषीले यसलाई जाँचेका छैनन्।** केही वाक्यहरू अस्वाभाविक लाग्न सक्छन् वा गलत हुन सक्छन्। तपाईं नेपाली पढ्न सक्नुहुन्छ भने एक मिनेटमै सहयोग गर्न सक्नुहुन्छ।

## कसरी सहयोग गर्ने

1. Egosaru को नेपाली पेज खोल्नुहोस्: <https://gstudio1.com/suggest/ne/posts/google>
2. कुनै वाक्य ठीक नलागेमा [अनुवाद सुधार फारम](https://github.com/YukiNakazawaAnzu/egosaru-i18n/issues/new/choose) खोल्नुहोस्, "नेपाली" छान्नुहोस्, त्यो वाक्य टाँस्नुहोस् र त्यो कस्तो हुनुपर्छ भनेर लेख्नुहोस्। तपाईं नेपालीमै लेख्न सक्नुहुन्छ।
3. GitHub खाता छैन? त्यसको सट्टा [सम्पर्क फारम](https://gstudio1.com/suggest/ne/contact) प्रयोग गर्नुहोस्।

एउटा वाक्य मात्र पनि ठूलो सहयोग हो। तपाईं GitHub मा अभ्यस्त हुनुहुन्छ भने [`lang/ne.json`](../lang/ne.json) सिधै सम्पादन गरेर pull request पनि पठाउन सक्नुहुन्छ।

## धन्यवाद

उपयोगी सुधार पठाउनेहरूले धन्यवादस्वरूप बढी सीमा भएको निःशुल्क API की पाउन सक्छन्। बस आफ्नो रिपोर्टमा यसबारे उल्लेख गर्नुहोस्। तपाईंको अनुमति भएमा हामी तपाईंको नाम [CONTRIBUTORS.md](../CONTRIBUTORS.md) मा समावेश गर्नेछौं।
