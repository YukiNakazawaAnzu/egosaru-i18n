# עזרה בשיפור Egosaru בעברית

[Egosaru](https://gstudio1.com/suggest/he/posts/google) הוא כלי חינמי שאוסף בבת אחת הצעות חיפוש (השלמה אוטומטית) מ-Google, Bing, YouTube ושירותים נוספים. הכלי זמין ב-50 שפות.

**הטקסט בעברית נכתב בעזרת בינה מלאכותית, ועדיין לא נבדק בידי דוברי עברית כשפת אם.** חלק מהמשפטים עשויים להישמע לא טבעיים או להיות שגויים. מי שקורא עברית יכול לעזור תוך דקה.

## איך אפשר לעזור

1. לפתוח עמוד של Egosaru בעברית: <https://gstudio1.com/suggest/he/posts/google>
2. אם משפט נשמע לא נכון, לפתוח את [טופס תיקון התרגום](https://github.com/YukiNakazawaAnzu/egosaru-i18n/issues/new/choose), לבחור "עברית", להדביק את המשפט ולכתוב איך הוא צריך להיות. אפשר לכתוב בעברית.
3. אין חשבון GitHub? אפשר להשתמש ב[טופס יצירת הקשר](https://gstudio1.com/suggest/he/contact) במקום.

גם משפט אחד הוא עזרה גדולה. מי שמכיר את GitHub יכול גם לערוך ישירות את [`lang/he.json`](../lang/he.json) ולפתוח pull request.
