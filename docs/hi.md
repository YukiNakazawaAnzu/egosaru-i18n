# हिन्दी में Egosaru को बेहतर बनाने में मदद करें

[Egosaru](https://gstudio1.com/suggest/hi/posts/google) एक मुफ़्त टूल है जो Google, Bing, YouTube और दूसरी सेवाओं के सर्च सुझाव (ऑटोकम्प्लीट) एक साथ इकट्ठा करता है। यह 50 भाषाओं में उपलब्ध है।

**हिन्दी टेक्स्ट AI से लिखा गया है और अभी तक किसी मातृभाषी ने इसकी जाँच नहीं की है।** कुछ वाक्य अटपटे लग सकते हैं या गलत हो सकते हैं। अगर आप हिन्दी पढ़ सकते हैं, तो बस एक मिनट में मदद कर सकते हैं।

## मदद कैसे करें

1. Egosaru का हिन्दी पेज खोलें: <https://gstudio1.com/suggest/hi/posts/google>
2. अगर कोई वाक्य ठीक न लगे, तो [अनुवाद सुधार फ़ॉर्म](https://github.com/YukiNakazawaAnzu/egosaru-i18n/issues/new/choose) खोलें, "हिन्दी" चुनें, वह वाक्य पेस्ट करें और लिखें कि उसे कैसा होना चाहिए। आप हिन्दी में लिख सकते हैं।
3. GitHub अकाउंट नहीं है? तो इसकी जगह [संपर्क फ़ॉर्म](https://gstudio1.com/suggest/hi/contact) का इस्तेमाल करें।

एक वाक्य भी बड़ी मदद है। अगर आप GitHub से परिचित हैं, तो [`lang/hi.json`](../lang/hi.json) को सीधे एडिट करके pull request भी भेज सकते हैं।

## धन्यवाद

उपयोगी सुधार भेजने वालों को धन्यवाद के तौर पर ज़्यादा सीमा वाली मुफ़्त API कुंजी मिल सकती है। बस अपनी रिपोर्ट में इसका ज़िक्र कर दें। आपकी अनुमति से, हम आपका नाम [CONTRIBUTORS.md](../CONTRIBUTORS.md) में शामिल करेंगे।
