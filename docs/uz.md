# Egosaruning oʻzbekcha talqinini yaxshilashga yordam bering

[Egosaru](https://gstudio1.com/suggest/uz/posts/google) — Google, Bing, YouTube va boshqa xizmatlardagi qidiruv takliflarini (avtomatik toʻldirish) bir martada yigʻib beradigan bepul vosita. U 50 tilda mavjud.

**Oʻzbekcha matnlar sunʼiy intellekt yordamida yozilgan va hali ona tili oʻzbek tili boʻlgan kishi tomonidan tekshirilmagan.** Ayrim gaplar gʻalati eshitilishi yoki xato boʻlishi mumkin. Agar oʻzbekcha oʻqiy olsangiz, bir daqiqada yordam bera olasiz.

## Qanday yordam berish mumkin

1. Egosaruning oʻzbekcha sahifasini oching: <https://gstudio1.com/suggest/uz/posts/google>
2. Agar biror gap notoʻgʻri tuyulsa, [tarjimani tuzatish shaklini](https://github.com/YukiNakazawaAnzu/egosaru-i18n/issues/new/choose) oching, «Oʻzbekcha»ni tanlang, gapni joylashtiring va u qanday boʻlishi kerakligini yozing. Oʻzbek tilida yozishingiz mumkin.
3. GitHub hisobingiz yoʻqmi? Unda [aloqa shaklidan](https://gstudio1.com/suggest/uz/contact) foydalaning.

Bitta gap ham katta yordam. GitHub bilan ishlashga oʻrgangan boʻlsangiz, [`lang/uz.json`](../lang/uz.json) faylini toʻgʻridan-toʻgʻri tahrirlab, pull request ham yuborishingiz mumkin.

## Rahmat

Foydali tuzatishlar yuborganlar minnatdorchilik sifatida yuqoriroq limitli bepul API kalitini olishlari mumkin. Buni xabaringizda eslatib oʻtsangiz kifoya. Ruxsatingiz bilan ismingizni [CONTRIBUTORS.md](../CONTRIBUTORS.md) roʻyxatiga kiritamiz.
