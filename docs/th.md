# ช่วยปรับปรุง Egosaru ภาษาไทยให้ดียิ่งขึ้น

[Egosaru](https://gstudio1.com/suggest/th/posts/google) เป็นเครื่องมือฟรีที่รวบรวมคำแนะนำการค้นหา (การเติมคำอัตโนมัติ) จาก Google, Bing, YouTube และบริการอื่น ๆ ได้ในครั้งเดียว ใช้งานได้ 50 ภาษา

**ข้อความภาษาไทยเขียนด้วย AI และยังไม่ได้ผ่านการตรวจจากเจ้าของภาษา** บางประโยคอาจฟังดูไม่เป็นธรรมชาติหรือผิดพลาด หากคุณอ่านภาษาไทยได้ ใช้เวลาเพียงนาทีเดียวก็ช่วยได้แล้ว

## วิธีช่วย

1. เปิดหน้า Egosaru ภาษาไทย: <https://gstudio1.com/suggest/th/posts/google>
2. หากเจอประโยคที่ฟังดูแปลก ให้เปิด[แบบฟอร์มแก้ไขคำแปล](https://github.com/YukiNakazawaAnzu/egosaru-i18n/issues/new/choose) เลือก "ไทย" วางประโยคนั้น แล้วเขียนว่าควรเป็นอย่างไร เขียนเป็นภาษาไทยได้เลย
3. หากไม่มีบัญชี GitHub ใช้[แบบฟอร์มติดต่อ](https://gstudio1.com/suggest/th/contact)แทนได้

แม้เพียงประโยคเดียวก็ช่วยได้มาก หากคุณคุ้นเคยกับ GitHub ก็สามารถแก้ไข [`lang/th.json`](../lang/th.json) โดยตรงแล้วส่ง pull request ได้เช่นกัน
