# 協助改善繁體中文版 Egosaru

[Egosaru](https://gstudio1.com/suggest/zh-tw/posts/google) 是一款免費工具，可以一次取得 Google、Bing、YouTube 等服務的搜尋建議（自動完成）。支援 50 種語言。

**繁體中文版的文字是由 AI 撰寫，還沒有經過母語人士確認。** 有些句子可能讀起來不太自然，甚至有錯誤。如果您看得懂中文，只要花一分鐘就能幫上忙。

## 如何協助

1. 打開繁體中文版的 Egosaru 頁面：<https://gstudio1.com/suggest/zh-tw/posts/google>
2. 如果覺得哪個句子怪怪的，請開啟[翻譯修正表單](https://github.com/YukiNakazawaAnzu/egosaru-i18n/issues/new/choose)，選擇「繁體中文」，貼上該句子，並寫下應該怎麼寫比較好。用中文填寫就可以了。
3. 沒有 GitHub 帳號嗎？也可以改用[聯絡表單](https://gstudio1.com/suggest/zh-tw/contact)。

即使只有一句，也是很大的幫助。如果您熟悉 GitHub，也可以直接編輯 [`lang/zh-tw.json`](../lang/zh-tw.json) 並送出 pull request。
