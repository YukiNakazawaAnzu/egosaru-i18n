# मराठीतील Egosaru अधिक चांगले करण्यासाठी मदत करा

[Egosaru](https://gstudio1.com/suggest/mr/posts/google) हे एक मोफत टूल आहे, जे Google, Bing, YouTube आणि इतर सेवांमधील शोध सूचना (ऑटोकम्प्लीट) एकाच वेळी गोळा करते. ते 50 भाषांमध्ये उपलब्ध आहे.

**मराठी मजकूर AI च्या मदतीने लिहिला आहे आणि अजून कोणत्याही मराठी भाषकाने तो तपासलेला नाही.** काही वाक्ये अनैसर्गिक वाटू शकतात किंवा चुकीची असू शकतात. तुम्ही मराठी वाचू शकत असाल, तर फक्त एका मिनिटात मदत करू शकता.

## मदत कशी करावी

1. Egosaru चे मराठी पान उघडा: <https://gstudio1.com/suggest/mr/posts/google>
2. एखादे वाक्य खटकले, तर [भाषांतर दुरुस्ती फॉर्म](https://github.com/YukiNakazawaAnzu/egosaru-i18n/issues/new/choose) उघडा, "मराठी" निवडा, ते वाक्य पेस्ट करा आणि ते कसे असायला हवे ते लिहा. तुम्ही मराठीत लिहू शकता.
3. GitHub खाते नाही? त्याऐवजी [संपर्क फॉर्म](https://gstudio1.com/suggest/mr/contact) वापरा.

एक वाक्यसुद्धा मोठी मदत आहे. तुम्हाला GitHub ची सवय असेल, तर तुम्ही [`lang/mr.json`](../lang/mr.json) थेट संपादित करून pull request देखील पाठवू शकता.

## धन्यवाद

उपयुक्त दुरुस्त्या पाठवणाऱ्यांना आभार म्हणून जास्त मर्यादेची मोफत API की मिळू शकते. फक्त तुमच्या अहवालात तसे नमूद करा. तुमच्या परवानगीने आम्ही तुमचे नाव [CONTRIBUTORS.md](../CONTRIBUTORS.md) मध्ये समाविष्ट करू.
