# Helfen Sie mit, Egosaru auf Deutsch zu verbessern

[Egosaru](https://gstudio1.com/suggest/de/posts/google) ist ein kostenloses Tool, das Suchvorschläge (Autovervollständigung) von Google, Bing, YouTube und weiteren Diensten in einem Durchgang sammelt. Es ist in 50 Sprachen verfügbar.

**Der deutsche Text wurde mit KI erstellt und noch nicht von Muttersprachlern geprüft.** Manche Sätze klingen vielleicht unnatürlich oder sind fehlerhaft. Wenn Sie Deutsch sprechen, können Sie in einer Minute helfen.

## So können Sie helfen

1. Öffnen Sie eine Seite von Egosaru auf Deutsch: <https://gstudio1.com/suggest/de/posts/google>
2. Wenn ein Satz falsch klingt, öffnen Sie das [Übersetzungsformular](https://github.com/YukiNakazawaAnzu/egosaru-i18n/issues/new/choose), wählen Sie „Deutsch“, fügen Sie den Satz ein und schreiben Sie, wie er lauten sollte. Sie können auf Deutsch schreiben.
3. Kein GitHub-Konto? Nutzen Sie stattdessen das [Kontaktformular](https://gstudio1.com/suggest/de/contact).

Schon ein einziger Satz hilft sehr. Wenn Sie mit GitHub vertraut sind, können Sie [`lang/de.json`](../lang/de.json) auch direkt bearbeiten und einen Pull Request stellen.

## Vielen Dank

Wer hilfreiche Korrekturen schickt, kann als Dankeschön einen kostenlosen API-Schlüssel mit höheren Limits erhalten. Erwähnen Sie das einfach in Ihrer Meldung. Mit Ihrem Einverständnis nennen wir Ihren Namen in [CONTRIBUTORS.md](../CONTRIBUTORS.md).
