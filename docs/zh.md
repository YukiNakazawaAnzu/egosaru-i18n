# 帮助改进简体中文版 Egosaru

[Egosaru](https://gstudio1.com/suggest/zh/posts/google) 是一款免费工具，可以一次性获取 Google、Bing、YouTube 等服务的搜索联想词（自动补全）。支持 50 种语言。

**简体中文版的文字由 AI 撰写，尚未经过母语人士审校。** 有些句子可能读起来不自然，甚至有错误。如果您能读中文，只需一分钟就能帮上忙。

## 如何帮忙

1. 打开简体中文版 Egosaru 的页面：<https://gstudio1.com/suggest/zh/posts/google>
2. 如果发现读起来别扭的句子，请打开[翻译修正表单](https://github.com/YukiNakazawaAnzu/egosaru-i18n/issues/new/choose)，选择“简体中文”，粘贴原句，并写下应该怎么改。用中文填写即可。
3. 没有 GitHub 账号？也可以改用[联系表单](https://gstudio1.com/suggest/zh/contact)告诉我们。

哪怕只改一句，也是很大的帮助。如果您熟悉 GitHub，也可以直接编辑 [`lang/zh.json`](../lang/zh.json) 并提交 pull request。
