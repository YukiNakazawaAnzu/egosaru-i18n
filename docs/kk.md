# Egosaru құралының қазақша нұсқасын жақсартуға көмектесіңіз

[Egosaru](https://gstudio1.com/suggest/kk/posts/google) — Google, Bing, YouTube және басқа қызметтердің іздеу ұсыныстарын (автотолтыру) бірден жинап беретін тегін құрал. Ол 50 тілде қолжетімді.

**Қазақша мәтін жасанды интеллекттің көмегімен жазылды, әрі оны қазақ тілін ана тілі ретінде білетін ешкім әлі тексерген жоқ.** Кейбір сөйлемдер табиғи емес естілуі немесе қате болуы мүмкін. Қазақ тілін білсеңіз, бір минутта-ақ көмектесе аласыз.

## Қалай көмектесуге болады

1. Egosaru құралының қазақша беттерінің бірін ашыңыз: <https://gstudio1.com/suggest/kk/posts/google>
2. Сөйлем дұрыс естілмесе, [аударманы түзету формасын](https://github.com/YukiNakazawaAnzu/egosaru-i18n/issues/new/choose) ашып, «Қазақша» тілін таңдаңыз, сөйлемді қойып, оның қалай болуы керектігін жазыңыз. Қазақша жаза аласыз.
3. GitHub аккаунтыңыз жоқ па? Оның орнына [кері байланыс формасын](https://gstudio1.com/suggest/kk/contact) пайдаланыңыз.

Бір сөйлемнің өзі үлкен көмек. GitHub платформасын жақсы білсеңіз, [`lang/kk.json`](../lang/kk.json) файлын тікелей өңдеп, pull request жіберуіңізге де болады.
