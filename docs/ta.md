# தமிழில் Egosaru-ஐ மேம்படுத்த உதவுங்கள்

[Egosaru](https://gstudio1.com/suggest/ta/posts/google) என்பது Google, Bing, YouTube உள்ளிட்ட பல சேவைகளின் தேடல் பரிந்துரைகளை (தானியங்கு நிரப்புதல்) ஒரே நேரத்தில் சேகரித்துத் தரும் இலவசக் கருவி. இது 50 மொழிகளில் கிடைக்கிறது.

**தமிழ் உரை AI மூலம் எழுதப்பட்டது; தமிழைத் தாய்மொழியாகக் கொண்ட யாரும் இதுவரை இதைச் சரிபார்க்கவில்லை.** சில வாக்கியங்கள் இயல்பற்றதாகவோ தவறாகவோ இருக்கலாம். உங்களுக்குத் தமிழ் படிக்கத் தெரிந்தால், ஒரே நிமிடத்தில் உதவலாம்.

## எப்படி உதவுவது

1. Egosaru-வின் தமிழ்ப் பக்கத்தைத் திறக்கவும்: <https://gstudio1.com/suggest/ta/posts/google>
2. ஏதேனும் வாக்கியம் சரியில்லை என்று தோன்றினால், [மொழிபெயர்ப்புத் திருத்தப் படிவத்தைத்](https://github.com/YukiNakazawaAnzu/egosaru-i18n/issues/new/choose) திறந்து, "தமிழ்" என்பதைத் தேர்ந்தெடுத்து, அந்த வாக்கியத்தை ஒட்டி, அது எப்படி இருக்க வேண்டும் என்று எழுதுங்கள். நீங்கள் தமிழிலேயே எழுதலாம்.
3. GitHub கணக்கு இல்லையா? அதற்குப் பதிலாக [தொடர்புப் படிவத்தைப்](https://gstudio1.com/suggest/ta/contact) பயன்படுத்துங்கள்.

ஒரு வாக்கியம்கூடப் பெரிய உதவிதான். GitHub உங்களுக்குப் பழக்கமானது என்றால், [`lang/ta.json`](../lang/ta.json) கோப்பை நேரடியாகத் திருத்தி pull request-உம் அனுப்பலாம்.
