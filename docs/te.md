# తెలుగులో Egosaru మరింత మెరుగయ్యేందుకు సహాయం చేయండి

[Egosaru](https://gstudio1.com/suggest/te/posts/google) అనేది Google, Bing, YouTube వంటి సేవల నుంచి శోధన సూచనలను (ఆటోకంప్లీట్) ఒకేసారి సేకరించే ఉచిత టూల్. ఇది 50 భాషల్లో అందుబాటులో ఉంది.

**తెలుగు పాఠాన్ని AI తో రాశాం, ఇంకా తెలుగు మాతృభాషగా ఉన్నవారెవరూ దీన్ని సరిచూడలేదు.** కొన్ని వాక్యాలు అసహజంగా అనిపించవచ్చు లేదా తప్పుగా ఉండవచ్చు. మీరు తెలుగు చదవగలిగితే, ఒక్క నిమిషంలోనే సహాయం చేయవచ్చు.

## ఎలా సహాయం చేయాలి

1. Egosaru తెలుగు పేజీని తెరవండి: <https://gstudio1.com/suggest/te/posts/google>
2. ఏదైనా వాక్యం సరిగ్గా లేదనిపిస్తే, [అనువాద సవరణ ఫారమ్](https://github.com/YukiNakazawaAnzu/egosaru-i18n/issues/new/choose) తెరిచి, "తెలుగు" ఎంచుకుని, ఆ వాక్యాన్ని పేస్ట్ చేసి, అది ఎలా ఉండాలో రాయండి. మీరు తెలుగులోనే రాయవచ్చు.
3. GitHub ఖాతా లేదా? బదులుగా [సంప్రదింపు ఫారమ్](https://gstudio1.com/suggest/te/contact) ఉపయోగించండి.

ఒక్క వాక్యం సరిచేసినా అది పెద్ద సహాయమే. మీకు GitHub అలవాటు ఉంటే, [`lang/te.json`](../lang/te.json) ను నేరుగా సవరించి pull request కూడా పంపవచ్చు.
