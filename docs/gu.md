# ગુજરાતીમાં Egosaru ને વધુ સારું બનાવવામાં મદદ કરો

[Egosaru](https://gstudio1.com/suggest/gu/posts/google) એક મફત ટૂલ છે, જે Google, Bing, YouTube અને બીજી સેવાઓનાં શોધ સૂચનો (ઑટોકમ્પ્લીટ) એકસાથે ભેગાં કરે છે. તે 50 ભાષાઓમાં ઉપલબ્ધ છે.

**ગુજરાતી લખાણ AI થી લખાયેલું છે અને હજી સુધી કોઈ ગુજરાતીભાષીએ તેને તપાસ્યું નથી.** કેટલાંક વાક્યો અકુદરતી લાગી શકે અથવા ખોટાં હોઈ શકે. જો તમે ગુજરાતી વાંચી શકતા હો, તો માત્ર એક મિનિટમાં મદદ કરી શકો છો.

## મદદ કેવી રીતે કરવી

1. Egosaru નું ગુજરાતી પેજ ખોલો: <https://gstudio1.com/suggest/gu/posts/google>
2. કોઈ વાક્ય બરાબર ન લાગે, તો [અનુવાદ સુધારણા ફૉર્મ](https://github.com/YukiNakazawaAnzu/egosaru-i18n/issues/new/choose) ખોલો, "ગુજરાતી" પસંદ કરો, તે વાક્ય પેસ્ટ કરો અને તે કેવું હોવું જોઈએ તે લખો. તમે ગુજરાતીમાં લખી શકો છો.
3. GitHub એકાઉન્ટ નથી? તો તેના બદલે [સંપર્ક ફૉર્મ](https://gstudio1.com/suggest/gu/contact) નો ઉપયોગ કરો.

એક વાક્ય પણ મોટી મદદ છે. જો તમે GitHub થી ટેવાયેલા હો, તો [`lang/gu.json`](../lang/gu.json) સીધું સંપાદિત કરીને pull request પણ મોકલી શકો છો.
