# به بهتر شدن Egosaru فارسی کمک کنید

[Egosaru](https://gstudio1.com/suggest/fa/posts/google) ابزاری رایگان است که پیشنهادهای جست‌وجو (تکمیل خودکار) را از Google، Bing، YouTube و سرویس‌های دیگر یک‌جا جمع‌آوری می‌کند. این ابزار به 50 زبان در دسترس است.

**متن فارسی با هوش مصنوعی نوشته شده و هنوز هیچ فارسی‌زبانی آن را بررسی نکرده است.** ممکن است برخی جمله‌ها نامأنوس یا نادرست باشند. اگر فارسی می‌خوانید، می‌توانید در یک دقیقه کمک کنید.

## چطور می‌توانید کمک کنید

1. صفحه‌ای از Egosaru فارسی را باز کنید: <https://gstudio1.com/suggest/fa/posts/google>
2. اگر جمله‌ای به نظرتان درست نیامد، [فرم اصلاح ترجمه](https://github.com/YukiNakazawaAnzu/egosaru-i18n/issues/new/choose) را باز کنید، «فارسی» را انتخاب کنید، جمله را در آن بچسبانید و بنویسید که درستش چطور است. می‌توانید به فارسی بنویسید.
3. حساب GitHub ندارید؟ به‌جای آن از [فرم تماس](https://gstudio1.com/suggest/fa/contact) استفاده کنید.

حتی یک جمله هم کمک بزرگی است. اگر با GitHub آشنا هستید، می‌توانید [`lang/fa.json`](../lang/fa.json) را مستقیماً ویرایش کنید و یک pull request بفرستید.

## سپاسگزاریم

کسانی که اصلاحات مفیدی بفرستند، به رسم قدردانی می‌توانند یک کلید API رایگان با سقف استفادهٔ بالاتر دریافت کنند. کافی است در گزارش خود به آن اشاره کنید. با اجازهٔ شما، نامتان را در [CONTRIBUTORS.md](../CONTRIBUTORS.md) می‌آوریم.
