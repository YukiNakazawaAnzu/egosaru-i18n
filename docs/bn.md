# বাংলায় Egosaru আরও ভালো করতে সাহায্য করুন

[Egosaru](https://gstudio1.com/suggest/bn/posts/google) একটি বিনামূল্যের টুল, যা Google, Bing, YouTube সহ নানা সেবার সার্চ সাজেশন (অটোকমপ্লিট) একবারে সংগ্রহ করে। এটি 50টি ভাষায় পাওয়া যায়।

**বাংলা লেখাগুলো AI দিয়ে লেখা হয়েছে, এবং এখনও কোনো মাতৃভাষী এগুলো যাচাই করেননি।** কিছু বাক্য অস্বাভাবিক শোনাতে পারে বা ভুল হতে পারে। আপনি বাংলা পড়তে পারলে মাত্র এক মিনিটেই সাহায্য করতে পারেন।

## কীভাবে সাহায্য করবেন

1. Egosaru-এর বাংলা পাতা খুলুন: <https://gstudio1.com/suggest/bn/posts/google>
2. কোনো বাক্য ঠিক না লাগলে [অনুবাদ সংশোধনের ফর্ম](https://github.com/YukiNakazawaAnzu/egosaru-i18n/issues/new/choose) খুলুন, "বাংলা" বেছে নিন, বাক্যটি পেস্ট করুন এবং সেটি কেমন হওয়া উচিত তা লিখুন। আপনি বাংলাতেই লিখতে পারেন।
3. GitHub অ্যাকাউন্ট নেই? তাহলে [যোগাযোগ ফর্ম](https://gstudio1.com/suggest/bn/contact) ব্যবহার করুন।

একটি বাক্যও অনেক বড় সাহায্য। আপনি GitHub-এ অভ্যস্ত হলে সরাসরি [`lang/bn.json`](../lang/bn.json) সম্পাদনা করে একটি pull request-ও পাঠাতে পারেন।

## ধন্যবাদ

যাঁরা দরকারি সংশোধন পাঠাবেন, কৃতজ্ঞতা হিসেবে তাঁরা বেশি সীমার একটি বিনামূল্যের API কী পেতে পারেন। শুধু আপনার রিপোর্টে কথাটি উল্লেখ করুন। আপনার অনুমতি পেলে আমরা [CONTRIBUTORS.md](../CONTRIBUTORS.md)-তে আপনার নাম যুক্ত করব।
