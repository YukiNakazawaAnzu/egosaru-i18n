# Aidez-nous à améliorer Egosaru en français

[Egosaru](https://gstudio1.com/suggest/fr/posts/google) est un outil gratuit qui récupère en une seule fois les suggestions de recherche (saisie automatique) de Google, Bing, YouTube et d'autres services. Il est disponible en 50 langues.

**Le texte français a été rédigé avec l'IA et n'a pas encore été relu par un locuteur natif.** Certaines phrases peuvent sembler peu naturelles ou contenir des erreurs. Si le français est votre langue, vous pouvez nous aider en une minute.

## Comment aider

1. Ouvrez une page d'Egosaru en français : <https://gstudio1.com/suggest/fr/posts/google>
2. Si une phrase vous semble incorrecte, ouvrez le [formulaire de traduction](https://github.com/YukiNakazawaAnzu/egosaru-i18n/issues/new/choose), choisissez « Français », collez la phrase et indiquez comment elle devrait se lire. Vous pouvez écrire en français.
3. Pas de compte GitHub ? Utilisez plutôt le [formulaire de contact](https://gstudio1.com/suggest/fr/contact).

Une seule phrase, c'est déjà une grande aide. Si vous êtes à l'aise avec GitHub, vous pouvez aussi modifier directement [`lang/fr.json`](../lang/fr.json) et ouvrir une pull request.

## Merci

Les personnes qui envoient des corrections utiles peuvent recevoir, en remerciement, une clé API gratuite aux limites plus élevées. Il suffit de le préciser dans votre message. Avec votre accord, nous ajouterons votre nom à [CONTRIBUTORS.md](../CONTRIBUTORS.md).
