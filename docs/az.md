# Egosaru-nun Azərbaycan dilində daha yaxşı olmasına kömək edin

[Egosaru](https://gstudio1.com/suggest/az/posts/google) Google, Bing, YouTube və digər xidmətlərdən axtarış təkliflərini (avtomatik tamamlama) bir dəfəyə toplayan pulsuz alətdir. O, 50 dildə mövcuddur.

**Azərbaycan dilindəki mətnlər süni intellektlə yazılıb və hələ ana dili Azərbaycan dili olan biri tərəfindən yoxlanılmayıb.** Bəzi cümlələr qeyri-təbii səslənə və ya səhv ola bilər. Azərbaycan dilində oxuya bilirsinizsə, cəmi bir dəqiqə ərzində kömək edə bilərsiniz.

## Necə kömək etmək olar

1. Egosaru-nun Azərbaycan dilindəki səhifəsini açın: <https://gstudio1.com/suggest/az/posts/google>
2. Səhv səslənən cümlə görsəniz, [tərcümə düzəlişi formasını](https://github.com/YukiNakazawaAnzu/egosaru-i18n/issues/new/choose) açın, "Azərbaycanca" seçin, cümləni yapışdırın və onun düzgün variantını yazın. Azərbaycan dilində yaza bilərsiniz.
3. GitHub hesabınız yoxdur? Onda [əlaqə formasından](https://gstudio1.com/suggest/az/contact) istifadə edin.

Bircə cümlə də böyük köməkdir. GitHub ilə işləməyə öyrəşmisinizsə, [`lang/az.json`](../lang/az.json) faylını birbaşa redaktə edib pull request də göndərə bilərsiniz.

## Təşəkkür

Faydalı düzəlişlər göndərənlər təşəkkür olaraq daha yüksək limitli pulsuz API açarı əldə edə bilərlər. Sadəcə bunu bildirişinizdə qeyd edin. İcazənizlə adınızı [CONTRIBUTORS.md](../CONTRIBUTORS.md) siyahısına əlavə edəcəyik.
