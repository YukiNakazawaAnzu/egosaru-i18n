# Help improve Egosaru in English

[Egosaru](https://gstudio1.com/suggest/en/posts/google) is a free tool that collects search suggestions (autocomplete) from Google, Bing, YouTube and other services in one go. It is available in 50 languages.

**The English text was written with AI and has not been checked by a native speaker yet.** Some sentences may sound unnatural or be wrong. If you read English, you can help in a minute.

## How to help

1. Open a page of Egosaru in English: <https://gstudio1.com/suggest/en/posts/google>
2. If a sentence sounds wrong, open the [translation form](https://github.com/YukiNakazawaAnzu/egosaru-i18n/issues/new/choose), choose English, paste the sentence and write how it should read. You can write in English.
3. No GitHub account? Use the [contact form](https://gstudio1.com/suggest/en/contact) instead.

One sentence is already a big help. If you are comfortable with GitHub, you can also edit [`lang/en.json`](../lang/en.json) directly and open a pull request.
